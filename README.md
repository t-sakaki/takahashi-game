# 高橋是清 〜日本のケインズ〜

このプロジェクトは、日本の近代日本の経済官僚・高橋是清をテーマにした教育ゲーム集です。
5つのミニゲームを通じて、歴史的出来事と経済政策を体験し、現代の経済・政治問題へのつながりを学べます。

## ゲーム一覧

1. **高橋財政 〜円の支配者〜**  
   ターンベース経済シミュレーション。景気回復度・陸軍好感度・財政健全度の三つ巴を管理。

2. **二・二六 4:40AM**  
   サバイバル・ステルスアドベンチャー。二・二六事件前夜の官邸で高橋是清として生き延びるか、歴史を変えるか。

3. **金と円と艦と —Takahashi's Ledger—**  
   デッキ構築型カードゲーム。各時代の危機に合わせて資金調達デッキを構築。

4. **是清の相場帳 —From Gold Standard to Keynes—**  
   ビジュアルノベル＋経済推理アドベンチャー。相場の異常変動から黒幕を推理。

5. **円の錬金術師 —Takahashi's Alchemy—**  
   教育向けパズル＆リソースマネジメント。金本位制から管理通貨制への移行を錬金の比喩で体験。

## 遊び方

1. リポジトリをクローンまたは ZIP ダウンロード  
2. `index.html` をブラウザ（Chrome, Firefox, Safari, Edge）で開く  
3. メニューから好きなゲームを選択してプレイ
